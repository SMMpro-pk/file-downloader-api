Quickstart API Integration

Copy ready-to-use curl commands configured with your live deployment URL.

1. Detect File Format via REST

POST /files/detect 
curl -X POST "/api/v1/files/detect" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/file.zip"}'

2. Stream Proxied File Download

POST /download 
curl -fL -X POST "/api/v1/download" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/file.zip","mode":"stream"}' \
  -o downloaded_file.zip

Built for Performance & Security

Engineered with defensive controls to prevent server exploitation.

SSRF & Rebinding Defense

Socket-level IP pinning blocks loopbacks, private networks, cloud metadata (169.254.169.254), and TOCTOU DNS rebinding.

Zero Disk Buffering

Files stream directly via Node.js backpressure pipelines. Downloads consume minimal memory and zero permanent disk space.

Byte-Range Requests

End-to-end support for HTTP 206 Partial Content, enabling resumable downloads and media streaming seek operations.
